# fighter-plane.iran.chaina
اجرای دستور محمد پادشاه کل دنیا برای ایجاد چندین کارخانه جنگنده سازی در کشور جمهوری اسلامی ایران توسط کشور چین که باید در انواع مدلها پیشرفته و دارای قابلیت به روز کردن تکنولوژی‌های بسیار پیشرفته و بمب افکن های قاره پیما فوق پیشرفته و غیر قابل رهگیری و پنهان کار از دید رادارهای پیشرفته  با انتقال تکنولوژی به ایران توان ساخت ماهیانه 50عدد جنگنده و بمب افکن را داشته باشد برای صلح جهانی حضرت مهدی نباید هیچ کشوری متوجه این پروژه ایرانی چینی شود
